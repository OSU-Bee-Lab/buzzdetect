# requirements-onnx.txt, but onnxruntime-gpu in place of onnxruntime, with the

# need a recent enough driver, not a system CUDA install.

# up, covering far more machines. Both support Turing (GTX 16xx/20xx) and
# newer. Move this pin up only alongside a driver requirement you've checked.
